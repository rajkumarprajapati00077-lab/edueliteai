# Home page authority and visual refinement

## Goal
Give the EduElite home page a credible, human-designed academic identity for CA, CS, and CMA students.

## Changes
- Add a dedicated institute strip for ICAI, ICSI, and ICMAI using locally stored marks and clear non-endorsement wording.
- Rework the opening section into a more editorial, student-focused composition with warmer copy, richer colour balance, restrained depth, and clearer actions.
- Upgrade home-page typography to a premium editorial display face with a highly readable body face, loaded efficiently.
- Refine feature and service presentation to feel curated rather than machine-generated, while preserving every existing link.
- Polish navigation, spacing, mobile/tablet/desktop layouts, reduced-motion behavior, and visible focus states.
- Fix the current logo reference warning and validate the result in the browser at desktop and mobile sizes.

## Technical details
- Keep all colours and shadows in semantic theme tokens.
- Store authority assets locally; no hotlinked images.
- Keep institute names and marks informational and avoid implying affiliation or endorsement.
- Preserve the existing multi-theme system and authenticated navigation behavior.
