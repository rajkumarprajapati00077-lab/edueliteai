# Project decisions
- Keep Academic as the only theme in light mode and clear legacy display preferences, so every device has one consistent appearance.
- Keep the home page as a direct tool launcher with institute logos labelled as course references only, so navigation is quick without suggesting institutional endorsement.
- Treat Focus Music and repeat Copy Checker use as Pro entry points; show plans without pretending checkout or email evaluation is active.
- Keep the closing corporate illustration in the landing page with a lazy-loaded local asset and reduced-motion-aware animation, so it adds no initial loading or accessibility burden.
