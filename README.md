# Apex AI Academy

You are an elite Full-Stack Web Developer and UI/UX Designer. Your task is to build the MVP for a premium, high-performance SaaS educational platform designed specifically for CA, CS, and CMA professional students.

Tech Stack & Architecture:

Framework: React (using Vite) or Next.js.

Styling: Tailwind CSS with a "Glassmorphism" UI and Framer Motion for buttery-smooth page transitions.

3D Elements: Integrate React Three Fiber or a Spline 3D embed for a premium, interactive hero section.

Backend & DB Placeholder: Set up the utility files to connect to Supabase (Auth and PostgreSQL database).

Deployment Ready: Ensure the build structure is optimized for instant deployment on Netlify.

Design Language (Premium & Modern):

Theme: Dark mode by default (Deep Charcoal/Obsidian background) with vibrant, neon-accented gradients (Electric Blue and Purple) to signify AI integration.

Typography: Inter or Geist for ultra-clean, modern readability.

Vibe: Think "Stripe meets OpenAI." It should feel like an expensive, professional operating system, not a childish study app.

Core Deliverables (Generate these screens/components):

1. The Landing Page:

A sticky navigation bar with a frosted glass effect and a bold "Start Free Trial" button.

Hero Section: A bold headline ("The AI Operating System for Professional Students") with a 3D interactive graphic (e.g., a floating, glowing cube or abstract data nodes) rotating in the background.

Feature Grid: Three premium, glowing bento-box style cards highlighting: 1) AI Backlog Manager, 2) Bilingual Concept-to-Exam Translator, 3) AI Answer Auditor.

2. The Student Dashboard (Post-Login):

A sleek sidebar navigation menu.

Top Widget: A "Target Jan 2027" countdown timer with a progress ring showing the percentage of syllabus completed.

Main Area: A dynamic study calendar grid highlighting "Today's Targets" with clean checkboxes.

3. The AI Chatbot Interface (The Bilingual Translator):

A centralized chat window styled like ChatGPT but customized.

Input area with a toggle switch labeled "Explain in Hindi -> Output in Professional English."

Message bubbles should look clean, with distinct styling for "User Prompt" and "AI Response."

Instructions for the AI: > Do not generate generic placeholder text like "Lorem Ipsum." Use actual, contextual copy related to CA/CS/CMA studies, ICAI modules, and taxation. Generate the fully functional UI first, ensuring all components are responsive for mobile devices.
